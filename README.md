# ParseGraph (Ettenmoors)

A LOTRO ParseGraph build that records dummy parses in the Ettenmoors as well as on the usual housing dummies.

## Install

Copy the `Arebel` folder into:

`Documents\The Lord of the Rings Online\Plugins`

Load **ParseGraph** from Plugin Manager. Open it with `/parsegraph` or `/pg`.

## Ettenmoors dummies

Glân Vraig and Gramsfoot training dummies often do not announce DPS in `/say`. This build starts a parse from combat-log hits, records minute ticks, and saves when you leave combat (after at least 20 seconds).

The orginal plugin does not support the dummies in the moors, you can find it [here](https://www.lotrointerface.com/downloads/fileinfo.php?id=1288)
